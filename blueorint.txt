Berikut adalah Blueprint detail untuk Sistem Autentikasi (Login) yang terhubung langsung dengan alur pengisian profil:1. Blueprint Tabel users (Pusat Akses)Di database, tabel ini akan menjadi jembatan antara akun login dengan data guru.KolomTipe DataKeteranganidINT (PK)Auto IncrementusernameVARCHARBisa menggunakan NIK atau Nama Tanpa SpasipasswordVARCHARDisimpan dalam bentuk Hashed (Bcrypt)roleENUM'admin', 'guru', 'staf'guru_idINTFK ke teachers.id (Menghubungkan akun ke profil guru)tenant_idVARCHARMenentukan user ini milik sekolah manais_profile_completeTINYINT(1)0 = Belum lengkap, 1 = Lengkap2. Alur Login & Redirect (Logika Utama)Sistem harus cerdas dalam mengarahkan user setelah login:Input: User memasukkan username dan password.Verifikasi: Backend mencocokkan hash password di database.Check Status:Jika is_profile_complete === 0 $\rightarrow$ Redirect ke complete-profile.html?teacherId=...Jika is_profile_complete === 1 $\rightarrow$ Redirect ke dashboard.htmlToken: Kirim JWT (JSON Web Token) untuk disimpan di localStorage agar user tidak perlu login berulang kali.3. Blueprint File: login.htmlGunakan desain yang sudah Anda miliki namun pastikan ID elemennya bersih:Fields: Username & Password.Feedback: Gunakan SweetAlert2 untuk pesan "Password Salah" atau "User Tidak Ditemukan".Security: Tambahkan fitur "Toggle Password" (Lihat/Sembunyi) agar user tidak salah ketik di saat darurat.4. Detail Backend: authController.js (Logika server.js)Agar absensi aman, login harus menangani hal berikut:Pengecekan Subdomain: Jika user mengakses sdit.ypwi.sch.id, login hanya boleh mengizinkan user dengan tenant_id = 'SDIT'.Session Management: Simpan tenant_id dan absensi_method di dalam token, sehingga saat guru masuk ke dashboard, sistem sudah tahu mereka harus absen lewat HP atau lewat Scanner Gerbang.5. Strategi "Akun Perdana" (Cara Guru Masuk Pertama Kali)Karena ini deadline, Anda tidak mungkin menyuruh semua guru daftar (registrasi) sendiri-sendiri.Solusinya: Anda (Admin) melakukan Import CSV atau Seeding.Default Password: Semua guru diberi password default (misal: ypwi123 atau nik_masing_masing).Force Update: Saat pertama login, mereka langsung dipaksa melengkapi profil (termasuk mengganti password).
